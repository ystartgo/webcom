雙引擎 AI 控制台・系統操作與排障手冊

四大推論模式說明 (1+1>2)

🖥️ LM Studio / API 模式

連接本地 LM Studio (Port 1234) 或雲端 API (OpenAI/Claude)，具備頂級代碼推論與複雜工具調度能力。

⚡ WebGPU 瀏覽器純本機

無需安裝任何後端軟體，模型權重直接跑在瀏覽器與顯示卡顯存上，零網路延遲、100% 離線隱私。

🧠 雙引擎聯合思考 (1+1>2)

第一階段 WebGPU 快速拆解意圖與假說，第二階段 主模型深度批判驗證與決策執行，發揮極致協同效能！

🛡️ 監督排查模式 (雙 LLM 互查)

當任一方卡死、回應空白、或程式碼出現明顯缺陷時，另一方將自動介入進行審查、點出盲點、並提出修正方案。適用於除錯、疑難排解、與穩定性要求高之場景。

常駐程式 (Port 8001 Daemon) 啟動

點擊頂部 `[▶ 啟動常駐程式]` ➔ `[確認一鍵重啟 / 啟用]`，系統將自動啟動後端，連線成功後視窗會自動關閉，並賦予 AI 控制本地終端機與硬體的能力。

模擬純斷網驗證開關 ⭐ 新功能

頂部工具列新增 `[外網：連通]` 開關。點擊後立即切換至 `[純斷網模擬：已啟動]`（按鈕呈紅色警示），前端將全域封鎖所有非 127.0.0.1 / localhost 的外部請求（含 CDN、GitHub、HuggingFace 等），讓您無需拔網路線即可即時驗證 100% 純離線 / WinPE 環境運作狀態。再次點擊即可一鍵恢復外網。

⚡ WebGPU 模型 — 首次下載後永久快取

首次選用 WebGPU 模型（如 Qwen2.5-0.5B 約 350 MB）時，模型權重會自動從 HuggingFace 下載並永久儲存於瀏覽器快取。之後無論是否斷網，均可 0 秒瞬間載入在顯卡上運算，不需重複下載！

1. 本地 Shell (Local Shell / WSL / WinPE CMD)

執行本地命令列指令。在 Windows / WinPE 環境下自動調度 `cmd.exe` 或 `powershell`，在 Linux/WSL 下調用 `bash`。

2. Web Serial (瀏覽器直連串口) ⭐ 推薦

透過 Chrome / Edge 內建 Web Serial API 直接操控 USB 轉串口（COM Port / UART）。完全無需啟動 8001 Daemon，也不需要任何驅動程式！ 點擊「連線設備」選擇 COM 埠即可即時收發資料。

3. TCP/IP: SSH 與 Telnet 遠端連線

設定遠端伺服器或路由器 IP、Port、帳號密碼後點擊「套用連線」，AI Agent 能透過後端 Daemon 自動發送 SSH / Telnet 指令進行遠端設備維護。

快捷指令選單 (輸入 / 快速呼叫)

在輸入框輸入 / 即可呼叫快捷指令選單，支援上下鍵與 Enter 鍵直接選取：

  • /左側有什麼查看看：讀取並分析左側終端機畫面中的日誌與回傳。
  • /探測設備指令：自動向串口或終端發送 help 指令並解析指令清單。
  • /Windows系統排查：調用 RAG 知識庫診斷網卡、服務與通訊埠。
  • /OpenWrt路由器排查：診斷 UCI 網路、dnsmasq 與 Failsafe 救援。
  • /UBoot引導與串口排查：排查嵌入式開機參數、TFTP 載入與串口異常。

RAG 本地知識庫擴充

點擊頂部 `[知識庫管理]`，可隨時上傳 .txt / .md / .json 排障手冊。系統會自動進行語意分塊並建立本機倒排索引，AI 推論時將自動檢索並引用相關內容！

100% 斷網離線運作機制

所有前端樣式（TailwindCSS）、圖示（Lucide）與 Markdown 解析器已完整收錄在 ./assets/ 本機目錄中。拔除網路線（無網際網路環境）也能 0 秒瞬間開啟！

WinPE 維護隨身碟轉移與開機自啟

  1. 將整份 Webcom 資料夾（或解壓 Webcom_WinPE_Portable.zip）複製到 WinPE 隨身碟。
  2. WinPE 系統開機後，直接雙擊 `WinPE_Autorun.bat`。
  3. 系統將自動利用內嵌的綠色 .\python\ 執行環境啟動 Daemon，並自動以瀏覽器開啟 Web 控制台，隨插即用！
Q1: LM Studio 提示 Failed to fetch / CORS 錯誤？

A: LM Studio 需允許跨域存取。請在終端機啟動：lms server start --cors --port 1234，或在 LM Studio 本地伺服器面板勾選 Enable CORS。亦可直接切換至「⚡ WebGPU 瀏覽器純本機」模式。

Q2: 常駐程式 (Port 8001) 連不上或被舊進程佔用？

A: 點擊頂部「常駐程式狀態」開啟面板，點擊 `[確認一鍵重啟 / 啟用]`，系統會自動強制終止佔用 8001 端口的舊行程並重新乾淨拉起服務。

Q3: WebGPU 模型下載進度與顯卡支援？

A: 首次使用 WebGPU 模型（如 Qwen2.5-0.5B 約 350MB）會自動下載並永久快取在瀏覽器中。支援 Chrome 113+ / Edge 等支援 WebGPU 的現代瀏覽器，推論時直接在顯卡上高速運算！

Q4: WebGPU 載入 3B 模型時閃退（exit code 1 / OOM）？

A: 顯存（VRAM）不足所致。解決方法：切換至較小的模型（推薦 Qwen2.5-0.5B 約 350MB），或關閉其他佔用 GPU 的應用程式後重試。若您的顯卡 VRAM 低於 4GB，建議改用 LM Studio / 後端 API 模式，將運算交給系統主記憶體處理。

Q5: LM Studio 回應時對話框空白但底部有 Token 統計？

A: 這是已知 DOM 節點脫離 Bug（v0.9.9 前舊版）。症狀：模型自動偵測到模型名稱時，舊版使用 innerHTML += 導致瀏覽器重建 DOM 並銷毀串流文字節點，回應全部寫入已脫離的無效節點，畫面空白但 token 統計有數值。此 Bug 已於 v1.0.0 修復，改用 insertBefore(badge, textBlock) 安全插入，串流渲染完整正常。請確保使用最新版本。

Q6: 切換語系（中↔英）後 AI 回應顯示 0 tokens？

A: 舊版切換語系時會插入語系提示詞至上下文（context），導致後端判斷 token 計算異常為 0。v1.0.0 已修復：語系切換僅更新 UI 顯示文字，不再汙染對話 context，AI 回應 token 統計完全正常。如仍遇到此問題，請點擊 「清除畫面」 重置對話後重試。
